Equipment Maintenance RAG System

Elite Material Co., Ltd. On-premises with cloud fallback, 2026

A retrieval-augmented question-answering system for equipment maintenance, served on premises with a cloud fallback.

  1. Question
  2. Hybrid retrieval BM25Dense vectors
  3. Rank fusionReciprocal Rank Fusion
  4. Relevance scoringLLM, pointwise, run concurrently
  5. Confidence routing On-premises LLMAzure OpenAI when evidence is thin
  • Designed hybrid BM25 and dense retrieval merged with Reciprocal Rank Fusion, measured on a 60-question evaluation set.
  • Implemented LLM-based pointwise relevance scoring with asynchronous concurrency to shorten the wait before the first token.
  • Routed queries by confidence between the on-premises RAG path and Azure OpenAI, so the cloud is used only when retrieved evidence is insufficient.
  • Deployed on-premises LLMs with vLLM and automated builds and deployments with Docker and GitLab CI/CD.
Precision@10
80% to 95%

50% shorter
